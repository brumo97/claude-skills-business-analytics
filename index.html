The problem

Raw data is not yet information.

Companies hold large volumes of sales data, but turning raw records into reliable analysis requires consistent procedures for validation, processing and visualization — every single time.

The approach

Write the procedure once. Reuse it.

This project used Claude Code, Python and three reusable Skills — written instructions that standardize how data is profiled, charted and reported — and applied them to a year of retail sales.

03

Execution

Five steps, from a raw CSV to a decision-ready report.

  1. 01

    Data Preparation

    Structure and quality checks on the CSV. Fixes applied to the reference file: the “Acessórios” category standardized, 7 discounts recalculated and 3 order totals corrected.

  2. 02

    Reusable Skills

    Three core Skills written to standardize the work: data-profile-conventions, chart-patterns and report-style.

  3. 03

    Data Analysis

    Exploration of the 500 orders by category, product, region, seller, channel, status and month.

  4. 04

    Data Visualization

    Six charts produced from the dataset with one visual standard: orange #D4631A + dark gray, bold titles, labeled axes, subtle grid, 150 dpi.

  5. 05

    Executive Reporting

    Findings organized in an executive report: conclusion first, then evidence, every number tied to a source, limitations stated.

Skills architecture

Each Skill defines a role, a protocol, absolute rules and an output format. Click a card to read the real excerpt.

Core 01

data-profile-conventions

Profiles the quality of any CSV dataset and reports objective facts only — no business recommendations.

Procedure
Shape and types → % nulls → IQR outliers → category spelling → duplicates, dates, impossible values, derived-column formula.
Benefit
Every dataset is checked the same way before anyone draws a conclusion.
## Regras absolutas

- NUNCA modifique o arquivo original
- NUNCA crie arquivos — o relatório vai só na conversa
- NUNCA faça recomendações — só reporte fatos
- Percentuais de nulos: sempre com 1 casa decimal (ex: 8.8%)

.claude/skills/data-profile-conventions/SKILL.md

Core 02

chart-patterns

Generates clear, standardized charts with Python and matplotlib, choosing the chart type from the question.

Procedure
Read data → pick type (distribution, comparison, time, correlation) → run Python inline → save PNG to output/charts/.
Benefit
Six charts that look like one coherent set, with predictable file names.
## Padrões visuais obrigatórios

- Paleta: #D4631A (laranja), #2D2D2D (cinza escuro)
- Título: bold, tamanho 14
- Sempre incluir: título, labels dos eixos, grid sutil
- Resolução: 150 dpi mínimo | Formato: PNG

.claude/skills/chart-patterns/SKILL.md

Core 03

report-style

Turns raw analysis into a clear executive narrative for decision-makers. Invoked manually only.

Procedure
Read the analyses → pick the 3–5 most relevant insights → fixed structure → save as output/relatorio-executivo-[date].md.
Benefit
Concrete numbers, cited sources, and limitations in their own section.
## Princípios de escrita

- Linguagem executiva: direta, sem jargão estatístico
- Cada seção começa com a conclusão — depois a evidência
- Números concretos sempre: nunca "muito" ou "bastante"
- Limitações dos dados vão na seção de observações

.claude/skills/report-style/SKILL.md

Results

Figures confirmed against the executive report and the dataset (2024 sales, 500 orders).

Gross recorded value R$ 1,672,029.36 All 500 orders, any status
Valid revenue R$ 1,427,333.56 Delivered + In transit
Valid orders 415 326 delivered · 89 in transit
Cancelled or returned 85 60 cancelled · 25 returned
Cancellations & returns value R$ 244,695.80 14.6% of gross value

How to read these numbers

  • Valid revenue = orders Delivered + In transit. It is not the same as delivered revenue (R$ 1,146,226.64, already confirmed).
  • Not profit. The dataset has no product cost, so no margin or profit can be calculated — only revenue.
  • The charts use gross values (all statuses, as generated by chart-patterns). The report uses valid revenue. That is why shares can differ slightly (e.g. Notebooks: 36.6% gross vs 36.7% valid).

Business insights

Documented in the executive report. Valid-revenue basis.

36.7%

Notebooks carry the revenue

R$ 524,081.90 of valid revenue. One product, the Notebook Gamer X, alone accounts for 17.7% — a concentration risk.

24.1%

Channels don't perform alike

Partner and Website lead with 46.1% of valid revenue. The App has the lowest revenue and loses 24.1% of its orders — almost twice the Partner channel (12.3%).

14.6%

Cancellations & returns

R$ 244,695.80 of gross value lost: 60 cancelled orders (R$ 160,305.88) and 25 returned (R$ 84,389.92).

8.8%

Orders with no seller

44 records have no seller: R$ 89,312.20 of valid revenue (6.3%) can't be attributed — and these orders show the highest loss rate (27.3%).

R$ 0

No cost data, no profit view

The dataset has no product cost. It shows what sells most, not what is profitable — no margin or profit is claimed anywhere.

28.9%

Many orders, little revenue

Accessories are 28.9% of valid orders (120 of 415) but only 3.5% of valid revenue (R$ 49,380.28).

Conclusion first, evidence second.

  • Sales summary with concrete numbers and a source tag ([F1], [F2], [F3]) on every figure.
  • Data quality verdict: reliable base — no duplicates, no invalid dates, all 500 totals match quantity × price × (1 − discount); 83 blank fields in 3 columns.
  • Breakdowns by category, product, region, seller, channel and month.
  • Six risk alerts, including R$ 281,106.92 still in transit and 53 orders with 15–20% discounts.
  • Explicit limitations: no cost, no targets, one year only, no cancellation reason, no customer data.

05

Key takeaways

What this case shows, technically and for the business.

01

Reusable Workflows

Repetitive procedures deserve written, standardized instructions. A Skill is written once and applied the same way every time.

02

Data Quality

Validate before concluding. Profiling surfaced fixes and blank fields that would otherwise have distorted the rankings.

03

Automation & Productivity

Skills make procedures more consistent: same checks, same chart style, same report structure — less rework.

04

Data Storytelling

Six charts and one report turn 500 rows into something a manager can read in minutes.

05

Business Decision-Making

Indicators point to concrete questions: product dependence, App losses, unattributed orders, revenue still in transit.

06

Technical Organization

Clear separation of rules, Skills, source data and outputs — with protected files that are never modified.
